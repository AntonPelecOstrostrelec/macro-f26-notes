Macroeconomics F26 — One-Page Cheat Sheet (print & bring)

1. National Income Identity & Multipliers

Y = C + I + G  (closed)  |  Y = C + I + G + NX  (open)
C = a + b·Yd  |  Yd = Y − T  |  b = MPC ∈ (0,1)
Spriv = Y − T − C  |  Spub = T − G  |  S = Spriv + Spub
Gov multiplier = 1/(1−MPC)
Tax multiplier = −MPC/(1−MPC)
Balanced-budget multiplier = 1
Open-economy multiplier = 1/(1 − MPC + m)

2. IS-LM (closed economy)

IS: Y = C(Y−T) + I(r) + G  → slopes DOWN
LM: M/P = L(Y, r) typically Y − cr  → slopes UP
Solve IS=LM for (Y*, r*).
↑G or ↓T → IS right → Y↑, r↑ (crowding out: I↓)
↑M → LM right → Y↑, r↓

3. Mundell-Fleming (open, perfect K mobility)

r = r* (world rate)  |  ↑e (appreciation) → ↓NX
LM* is VERTICAL; IS* slopes down in (e, Y).
FloatingFixed
FiscalIneffectiveEffective
MonetaryEffectiveIneffective
Tariff (↑)Y same, e↑Y↑, e fixed
Memory: floating gives monetary, fixed gives fiscal.

4. Classical Production & Factor Markets

Cobb-Douglas: Y = A·Lα·Kβ. α+β = 1 → CRS, >1 IRS, <1 DRS.
RTS test: if doubling all inputs raises Y by ratio R: R>2 IRS, =2 CRS, <2 DRS
MPL = αY/L  |  MPK = βY/K
W/P = MPL  |  R/P = MPK
Labor income = αY (share α)  |  Capital income = βY

5. Money Market & Fisher

QTM: M·V = P·Y  → %ΔM + %ΔV = %ΔP + %ΔY
V, Y fixed → %ΔP ≈ %ΔM (money neutrality)
Fisher: i = r + πe
Real money demand: (M/P)d = L(Y, i)

6. Solow Growth (square-root case)

y = k1/2  |  Δk = sk1/2 − (δ+n+g)k
Steady state (Δk = 0):
k* = [s/(δ+n+g)]²
y* = √k* = s/(δ+n+g)
sy* = s·y*  |  c* = (1−s)·y*
Golden rule: MPK = δ + n + g (maximises c*)
Long-run per-capita growth = g (technology only).

7. Inflation, CPI, Phillips, Okun

CPI = FIXED basket weights (Laspeyres)
GDP deflator = CURRENT quantities (Paasche) = (Nom/Real)·100
Inflation π = (Pt − Pt−1)/Pt−1 · 100
Phillips: π = πe − β(u − un) + ν
Okun: ΔY/Y ≈ −β·(u − un); employment↑ ↔ Y↑ (positive); u↑ ↔ Y↓ (negative)

8. Consumption Theories

Keynes: C = a + b·Yd. APC = a/Y + b → falls as Y rises.
Friedman PIH: C = α·YP. Smooth via permanent income.
Modigliani LCH: C = (W + R·Y)/T. Smooth over lifetime.
Kuznets puzzle: APC constant in long run (PIH/LCH), falls in cross-section (Keynes).

9. GDP Concepts

GDP = value of final goods produced within country
GNP = GDP + net factor income from abroad
NNP = GNP − depreciation
Real GDP at base-year P; Nominal GDP at current P.

10. Quick Reflexes for T/F

Statement templateWatch out
"Doubling inputs raises Y by …"Compute ratio R
"MPC > 1" or "MPC < 0"FALSE always
"CPI uses changing weights"FALSE — fixed
"IS* is vertical (open)"FALSE — LM* is
"Okun: emp ↔ Y negative"FALSE — positive
"Real GDP at current prices"FALSE — nominal is
"QTM: ΔM not proportional to ΔP"FALSE — proportional
"Money neutrality affects real Y"FALSE — only nominal
Exam tactics: Show working step-by-step for partial credit. Define curves before using them ("IS represents combinations of (Y, r) where the goods market clears…"). Always state the multiplier formula before computing. Diagrams: label axes (Y on x; r/e/P on y) and curves clearly. For T/F, write the answer + 1 sentence — no more.
