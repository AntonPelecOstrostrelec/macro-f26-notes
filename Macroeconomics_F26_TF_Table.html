Top 3 prediction for F26 (highest probability):
  1. Returns-to-scale numerical trap — appeared in EVERY single T/F exam since V23. The pattern is always "doubling inputs raises output from X to Y. This is IRS/CRS/DRS." Compute the ratio Y/X. If >2 → IRS, =2 → CRS, <2 → DRS. Almost guaranteed to appear.
  2. Classical / money neutrality / QTM — appeared in 3 of 4 exams. Variations include "money neutrality affects real variables", "classical theory says factors are paid MP", "QTM says ΔM does not raise P proportionally" (false).
  3. MPC / consumption — Always a definition trap. Watch for "MPC > 1 but < 0" (impossible), reversed direction "MPC = ΔY/ΔC", or "Keynesian C depends on disposable income" (true).

V23a Consider a production technology in which doubling all inputs increases output from 120 to 180 units. This is referred to as increasing returns to scale (IRS). FALSE Output rose by only 50% (180/120 = 1.5 < 2), so this is decreasing returns to scale, not IRS. Returns to scale
V23b According to classical theory, firms demand each factor of production until that factor's marginal product equals its real factor price. TRUE Profit-maximization: hire L until MPL = W/P (real wage); hire K until MPK = R/P (real rental rate). Mankiw Ch. 3. Classical
V23c According to the Phillips curve, in the short run, we have to accept high unemployment if we want to reduce the inflation rate. TRUE Short-run Phillips curve: π = πe − β(u − un). To lower π below πe, u must rise above un (sacrifice ratio). Phillips
V23d Investments are fixed in the Keynesian cross and a function of the interest rate in the IS curve. TRUE In Keynesian cross, I = Ī (constant). The IS curve is derived precisely by letting I = I(r), generating the negative Y–r relation. IS-LM
V23e The marginal propensity to consume (MPC) shows how much income changes when there is a change in consumption. FALSE MPC = ∂C/∂Yd — it shows how consumption changes when disposable income changes, not the reverse. Wording is reversed. MPC
V23_REa The GDP deflator (GDPD) uses fixed weights while CPI (the consumer price index) uses changing weights. FALSE It is the opposite: CPI uses fixed basket weights (Laspeyres); GDP deflator uses current quantities (Paasche). CPI
V23_REb Consider a production technology in which doubling all inputs increases output from 120 to 250 units. This is referred to as increasing returns to scale (IRS). TRUE Output more than doubled (250/120 ≈ 2.08 > 2), so this is genuine increasing returns to scale. Returns to scale
V23_REc According to the quantity theory of money (QTM), increases in the money supply have no effect on real variables. TRUE Classical dichotomy / monetary neutrality: in the long run, ΔM affects only P (and nominal variables), not real Y, real r, or employment. Classical
V23_REd According to Okun's law, there is a negative relationship between employment and output (GDP). FALSE Okun's law gives a negative relationship between unemployment and output. Employment and output are positively related. Okun
V23_REe The IS curve is vertical in an open economy (Mundell-Fleming) because of the role of the exchange rate. FALSE In Mundell-Fleming with perfect capital mobility it is the LM* curve that is vertical (at Y where r = r*). The IS* curve slopes down in (e, Y) space. Mundell-Fleming
S25a The marginal propensity to consume (MPC) is always greater than 1 but less than 0. FALSE Mathematically impossible (no number is both >1 and <0). MPC is between 0 and 1: 0 < MPC < 1. MPC
S25b According to the classical school of thought, real variables like output and employment are not affected by nominal changes in the long run. TRUE Classical dichotomy and long-run money neutrality: real variables determined by real factors (capital, labor, technology), independent of nominal money supply. Classical
S25c Consider a production technology in which doubling all input increases output from 5 to 7 units, referred to as decreasing returns to scale (DRS). TRUE Doubling inputs raised output by only 40% (7/5 = 1.4 < 2). Output less than doubled = decreasing returns to scale. Returns to scale
S25d The Phillips curve suggests that, in the short run, reducing inflation requires accepting higher unemployment. TRUE Standard short-run Phillips curve trade-off — disinflation requires u > un temporarily. Phillips
S25e Real GDP is measured at current market prices, while nominal GDP is adjusted for inflation. FALSE Reversed: Nominal GDP is at current prices; Real GDP is at constant (base-year) prices and is therefore inflation-adjusted. GDP
S25_REa In the IS-LM model, an increase in government spending shifts the IS curve to the right, leading to higher income and higher interest rates. TRUE ↑G shifts IS rightward → along upward-sloping LM, both Y and r rise (textbook fiscal expansion in IS-LM). IS-LM
S25_REb According to the Keynesian consumption function, disposable income is the main determinant of consumption. TRUE Keynes: C = a + b·(Y − T); current disposable income is the primary driver of consumption. MPC
S25_REc An appreciation of a country's exchange rate reduces net exports, as exports become more expensive, and imports become cheaper. TRUE Appreciation makes domestic goods relatively more expensive abroad and foreign goods cheaper at home → X falls, M rises → NX falls. Mundell-Fleming
S25_REd Consider a production technology in which doubling all input increases output from 100 to 150 units; this is referred to as increasing returns to scale (IRS). FALSE Output rose only 50% (150/100 = 1.5 < 2). This is decreasing returns to scale, not IRS. Returns to scale
S25_REe According to the quantity theory of money (QTM), an increase in the money supply is a nominal change which does not increase prices by the same proportion. FALSE QTM (with V and Y constant): MV = PY → %ΔM = %ΔP. An increase in M raises P proportionally. Statement reverses the QTM result. Classical

Older-Exam Concept Statements (V19–V22 Equivalents)

Although V19–V22 didn't use explicit T/F format, the concepts tested in their short-answer questions can be reformulated as T/F. Master these — they fill in topics that V23+ T/F questions don't directly cover.

Statement (older-exam concept)AnswerWhy
If S > I in an open economy, the country must have a trade surplus. TRUE Identity: S − I = NX. S > I ⟺ NX > 0.
Under perfect capital mobility, the domestic interest rate must equal the world interest rate. TRUE Otherwise capital floods in/out instantly. Standard Mundell-Fleming assumption (V19_RE PS1, V20_RE PS1).
Under fixed exchange rates with perfect capital mobility, an expansionary monetary policy is effective at raising output. FALSE Monetary is INEFFECTIVE under fixed ER. ↑M would depreciate e; CB must buy back currency, undoing ΔM.
Frictional unemployment can be eliminated through good labour market policies. FALSE Frictional unemployment is the structural minimum due to time needed for job matching. It can be reduced (better info, retraining) but not eliminated. (V19 PS3, V22_RE PS3)
An exogenous adverse supply shock raises both prices and unemployment in the short run. TRUE SRAS shifts up: P↑, Y↓, and u↑ (via Okun's law). This is "stagflation." (V20 PS3, V22 PS3 — COVID and Russia/Ukraine examples)
According to Okun's law, a 1% increase in unemployment leads to roughly a 2% increase in GDP relative to potential. FALSE It's a 2% decrease. Sign reversed. Higher u → lower Y, not the other way around.
The government-spending multiplier is larger in absolute value than the tax multiplier. TRUE Spending multiplier = 1/(1−MPC). Tax multiplier = MPC/(1−MPC). With MPC = 0.75: spending = 4, tax = 3. Spending wins.
An expected future increase in income raises consumption today, according to Friedman's PIH. TRUE Forward-looking PIH: expected higher future income raises permanent income → raises C today via consumption smoothing. (V21 A2 Q5)
If the saving rate is below the golden rule rate, increasing saving raises consumption per worker in the long run. TRUE Below golden rule ⟹ MPK > δ+n+g. Raising s pushes k* toward kgold; c* increases (after a short transitional dip in c).
For a Cobb-Douglas function Y = KαL(1−α), labour income share equals α and capital share equals (1−α). FALSE Reversed. Labour gets the share of its own exponent (1−α); capital gets α. Read indices carefully.
Real GDP growth is procyclical with inflation according to the short-run Phillips curve. TRUE In booms (Y above Y̅), u falls below un → inflation rises. In recessions, opposite. So inflation moves with the cycle. (V21 A2 Q3)
Demand for goods in the domestic economy equals demand for domestic goods when there is a trade surplus. FALSE Equality holds only when NX = 0. With trade surplus (NX > 0), demand for domestic goods (= C+I+G+NX) is GREATER than demand within the domestic economy (= C+I+G). (V19 PS3 Q1)
The Fisher equation states that the real interest rate equals the nominal rate minus expected inflation. TRUE r = i − πe, rearranged from i = r + πe. (V19 PS1, V20_RE PS1, V22_RE PS2)
The opportunity cost of holding money in liquid form is the inflation rate. FALSE It's the nominal interest rate i (not just inflation). Holding cash forgoes nominal returns on alternative assets. (V19 PS1 Q3)
According to QTM, the inflation rate equals the money growth rate when velocity and real output are both constant. FALSE Inflation = money growth − real output growth. Even if V is constant, you must subtract %ΔY. Only if BOTH V and Y are constant does π = %ΔM. (V19_RE PS1, V20 PS2c)
In Mankiw's Solow model with both n and g, the long-run growth rate of output per worker equals g (technology growth). TRUE Capital deepening hits diminishing returns; only g sustains per-worker growth in the long run. Output per capita grows at g; total output Y grows at n+g.
